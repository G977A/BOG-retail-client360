# Retail Client 360 + Campaign Lab

End-to-end retail banking analytics on **synthetic** data: Oracle SQL warehouse →
PySpark feature pipeline → behavioural segmentation → campaign uplift measurement →
Power BI decision layer.

> ⚠️ All data in this repository is synthetic and generated by `src/generator`.
> No real customer or institutional data is used anywhere.

## Why this project exists

Most campaign reporting compares responders to non-responders and calls the
difference "impact". That number is almost always wrong, because the people who
respond were more likely to buy anyway.

This project makes that failure **measurable**: the data generator plants a known
persona and a known true uplift for every synthetic customer, so the correct answer
is known in advance. The analysis then shows how far the naive read drifts from the
truth, and how much of that gap a proper control group and uplift model recover.

+ It is for study purposes, as I strongly believe hands-on practice is the best method for studying :)

## Repository layout

| Path | Contents |
| --- | --- |
| `docs/` | Charter, data model, decision log - read `docs/00-charter.md` first |
| `infra/oracle/` | Docker Compose for a local Oracle Database Free instance |
| `sql/ddl/` | Schema definition: dimensions, facts, partitioning, indexes |
| `sql/analytics/` | Analytical SQL — cohorts, RFM, product penetration |
| `sql/checks/` | Data quality assertions run after every load |
| `src/generator/` | Synthetic data generation (personas, transactions, campaign response) |
| `src/ingest/` | Loading generated data into Oracle |
| `src/features/` | PySpark customer feature store |
| `src/segmentation/` | Clustering, model selection, segment profiling |
| `src/campaign/` | Targeting, control group design, uplift measurement |
| `powerbi/` | Power BI template (`.pbit`) and screenshots |
| `reports/` | Executive summary and slides |
| `notebooks/` | Exploration only — nothing here is a deliverable |

## Quickstart

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cd infra/oracle && docker compose up -d
```

See `docs/00-charter.md` for scope and `docs/01-data-model.md` for the schema.
