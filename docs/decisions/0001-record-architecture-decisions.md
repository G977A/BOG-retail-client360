# ADR-0001 — Record architecture decisions

**Status:** accepted

## Context

A portfolio project is read by people deciding whether I think clearly. The code
shows what I did; it does not show what I considered and rejected.

## Decision

Every non-obvious choice gets a short ADR here: context, decision, consequences.
Numbered, immutable once accepted — superseded rather than edited.

## Consequences

Writing them costs a few minutes each. In exchange, "why Oracle and not
Postgres?" in an interview has a written answer instead of an improvised one.
